## ⏳ 틈틈 (TeumTeum)

**남는 공백시간을, 나를 챙기는 시간으로.**

약속 전 10분, 수업과 수업 사이 20분, 이동 중 잠깐 생긴 15분. 다들 이런 애매한 시간엔 딱히 뭘 할지 몰라서 습관적으로 숏폼을 켜거나, 그냥 멍하니 흘려보내곤 합니다. 틈틈은 지금 남은 시간과 상황을 바탕으로, AI가 그 시간 안에 정확히 끝나는 웰니스 코스를 짜주는 서비스입니다.

## 💡 서비스 소개

**콘텐츠에 내 시간을 맞추지 말고, 내 시간에 콘텐츠를 맞춘다.**

명상이나 스트레칭 콘텐츠는 대부분 10분, 20분처럼 정해진 길이로 만들어져 있습니다. 그런데 정작 일상에서 우리에게 생기는 시간은 7분, 12분, 18분처럼 항상 애매합니다. 그러다 보니 콘텐츠를 중간에 끊거나, 아예 시작도 안 하고 다시 잠깐의 공백을 삼켜버리는 릴스를 켜게 됩니다.

틈틈은 반대로 접근했습니다. 사용자가 "지금 15분 남았어요"라고 말하면, 실제 콘텐츠 길이(영상 재생 시간, 활동 소요 시간)를 초 단위로 계산해서 그 15분 안에 시작부터 마무리까지 끝나는 개인맞춤형 코스를 구성합니다.

## 🤔 Problem

**왜 우리는 공백시간에 더 피곤해질까**

약속이나 일정 사이에 짧은 시간이 남으면, 갈 곳이 없어서 주변을 서성이거나, 딱히 필요하지도 않은 카페에 들어가거나, 유튜브 쇼츠를 무의식적으로 넘겨봅니다. 쉬려고 시작한 행동인데 오히려 자극적인 콘텐츠를 계속 소비하면서 도파민 과부하와 피로만 쌓입니다.

기존 명상·운동 서비스들은 대부분 긴 시간을 요구하거나, 정해진 콘텐츠 길이에 사용자가 자기 시간을 맞춰야 합니다. 결국 사람들은 공백시간을 잘 쓰고 싶어도, 자신의 남은 시간에 정확히 맞는 콘텐츠를 찾지 못하고 있습니다.

## 💡 Solution

**내 시간에 딱 맞는 AI 웰니스 코스**

틈틈은 남은 시간, 지금 있는 장소, 원하는 회복 방식, 다음 일정, 현재 상태 다섯 가지를 종합해서 지금 상황에 가장 맞는 코스를 구성합니다.

### 1️⃣ 시간을 알려줍니다

슬라이더로 남은 시간을 설정합니다. 5분부터 30분까지 가능합니다.

`5분 ━━━━━●━━━━ 30분`

"지금 17분 남았습니다"라고 입력하면, AI는 17분 안에 끝낼 수 있는 콘텐츠를 구성합니다.

### 2️⃣ 지금 상황을 알려줍니다

지금 있는 곳(이동 중 / 카페·실내 / 학교·회사 / 집 / 기타), 원하는 회복 방식(읽기 / 듣기 / 스트레칭 / 마음 정리, 복수 선택), 이 틈이 끝나면 할 일(수업·회의 / 친구·약속 / 업무·과제 / 귀가·휴식 / 없음 / 기타), 지금 가장 가까운 상태(피곤해요 / 긴장돼요 / 머릿속이 복잡해요 / 몸이 뻐근해요 / 피부가 신경 쓰여요, 복수 선택)를 답합니다.

### 3️⃣ AI가 지금 필요한 코스를 추천합니다

- 🧠 **읽기**: AI가 웰니스 원문을 지금 상황에 맞게 재구성한 짧은 글입니다.
- 🎧 **듣기**: 호흡·마음챙김 오디오 가이드, 혹은 관련 유튜브 콘텐츠입니다.
- 🧘 **스트레칭**: 목·어깨·손목·하체 등 부위별 스트레칭 가이드, 혹은 관련 유튜브 콘텐츠입니다. 일부 가이드는 앉아서만 가능한 동작이라 장소에 따라 추천 여부가 달라집니다.
- 🪞 **마음 정리**: 짧은 질문에 답하면서 생각을 정리하는 콘텐츠입니다.

여기에 맞는 활동이 하나도 없으면, 대신 **다음 준비-틈**이 들어갑니다. 다음 일정(예: "곧 친구를 만난다")에 맞춰 지금 감정을 정리하고 자연스럽게 넘어갈 수 있도록 AI가 짧은 준비 질문을 만들어줍니다.

### 4️⃣ 내가 발견한 콘텐츠도 학습시킵니다

틈틈 안에 없는 콘텐츠라도 상관없습니다. 인스타그램이나 유튜브 앱을 포함한 다양한 콘텐츠에서 우연히 발견한 스트레칭 영상, 마음이 편안해지는 영상이 있으면, 공유 버튼으로 틈틈에 바로 보낼 수 있습니다.

```text
다른 앱에서 유튜브 영상 시청 중
        ↓
공유 버튼 → 틈틈 선택
        ↓
AI가 제목·채널을 보고 회복 방식(듣기 / 스트레칭 / 마음 정리)으로 자동 분류
        ↓
다음 코스를 만들 때, 이 영상이 시간에 맞으면 우선적으로 추천에 반영
```

한 번 코스에 실제로 쓰인 영상은 다시 추천되지 않고, 같은 영상을 여러 번 공유해도 중복으로 쌓이지 않습니다. 분류가 한 번에 안 되더라도 다음 코스를 만들 때 자동으로 다시 시도하기 때문에, 사용자가 따로 신경 쓸 필요는 없습니다. 즉 틈틈이 미리 준비해둔 콘텐츠뿐 아니라, 사용자가 평소에 즐겨보던 콘텐츠까지 개인화의 재료가 됩니다.

## 🤖 AI 활용

틈틈의 AI는 콘텐츠를 추천하는 데서 끝나지 않습니다.

### ① 시간 기반 콘텐츠 생성

남은 시간을 기준으로, 실제 콘텐츠 길이를 초 단위까지 계산해서 그 시간에 최대한 가깝게 맞는 조합을 찾습니다.

```text
사용자 입력
남은 시간: 15분 / 현재 상태: 피곤함 / 현재 장소: 지하철 / 다음 일정: 친구와 약속

AI 구성
2분 스트레칭 가이드 + 5분 편안한 읽기 + 8분 관련 유튜브 콘텐츠
= 총 15분
```

(다음 일정 준비 질문은 위처럼 딱 맞는 활동 모듈이 이미 배정된 경우에는 들어가지 않고, 그런 모듈이 없을 때만 대신 들어가는 별도 구성입니다.)

중간에 마음에 안 드는 콘텐츠는 건너뛸 수 있고, 건너뛴 만큼의 시간은 사용 기록에 포함하지 않습니다. 그렇게 마지막 콘텐츠까지 도달했다면, 설정한 시간이 다 지나지 않았더라도 완료 처리됩니다.

### ② 상황 기반 코스 추천

남은 시간, 회복 방식 선호, 현재 장소, 기분·피로도, 다음 일정을 종합해서 지금 가장 필요한 활동을 우선 추천합니다.

## 📊 버린 시간의 자산화

틈틈에서 쓴 공백시간은 기록으로 남습니다.

> 이번 주 내가 나를 챙긴 시간 (예시): **85분**

무심코 숏폼을 보며 사라졌을 시간이, 나를 돌본 시간이라는 기록으로 바뀝니다. 마이페이지에서는 이번 주와 지난주 사용 시간을 비교하고, 가장 자주 선택한 회복 방식과 완료율이 가장 높은 시간대를 확인할 수 있습니다. 발견 탭에서는 사용자 관심사에 맞는 웰니스 아티클도 추천받을 수 있습니다.

## ✨ 핵심 기능

| 기능 | 설명 |
|---|---|
| ⏱️ 공백시간 설정 | 5~30분 사이, 슬라이더로 남은 시간을 설정합니다. |
| 🤖 AI 코스 생성 | 남은 시간에 최대한 정밀하게(초 단위 계산) 맞춘 웰니스 루틴을 생성합니다. |
| 🧠 읽기 · 🎧 듣기 | AI가 재구성한 글, 호흡 오디오 가이드, 관련 유튜브 콘텐츠를 제공합니다. |
| 🧘 스트레칭 | 부위별 스트레칭 가이드와 관련 유튜브 콘텐츠를 제공합니다. |
| 🪞 마음 정리 | 질문에 답하며 생각을 정리하는 콘텐츠를 제공합니다. |
| ✨ 다음 준비-틈 | 다음 일정에 맞춘 AI 준비 질문을 제공합니다. |
| ⏭️ 스킵 | 콘텐츠를 건너뛸 수 있고, 실제 사용한 시간만 기록에 반영됩니다. |
| 🔗 콘텐츠 공유 학습 | 다른 앱에서 공유한 유튜브 영상을 AI가 회복 방식으로 자동 분류하고, 시간이 맞을 때 다음 코스 추천에 우선 반영합니다. 분류 실패 시 다음 코스 생성 때 자동 재시도합니다. |
| 📊 틈 기록 | 완료한 코스와 이번 주·지난 주 사용 시간 비교를 확인할 수 있습니다. 만족도 평가는 다음 추천에 반영됩니다. |
| 📰 발견 탭 | 관심사 기반 AI 웰니스 아티클을 추천합니다. |

## 🌱 기존 서비스와의 차별점

| 기존 웰니스 서비스 | 틈틈 |
|---|---|
| 콘텐츠의 시간에 사용자가 맞춥니다. | 사용자의 시간에 콘텐츠가 맞춰집니다. |
| "이 명상 콘텐츠는 20분입니다." | "지금 13분 있으시군요. 13분 안에 끝나는 코스를 만들어드립니다." |

틈틈은 웰니스 콘텐츠의 종류보다, 사용자의 실제 생활 시간에 콘텐츠를 정밀하게 맞추는 경험에 집중합니다.

## 🎯 Target

약속 전 애매하게 시간이 남는 사람, 수업과 수업 사이 공강이 있는 대학생, 출퇴근·등하교 중 짧은 시간이 생기는 사람, 습관적으로 숏폼을 보는 시간을 줄이고 싶은 사람, 긴 명상이나 운동은 부담스럽지만 짧게라도 자신을 돌보고 싶은 사람이 대상입니다. 그중에서도 숏폼과 SNS 사용량이 높은 20~30대를 주요 타깃으로 합니다.

## 🏆 Track Fit

틈틈은 따로 시간을 내야 하는 웰니스가 아니라, 이미 일상에 존재하는 공백시간을 활용하는 서비스입니다.

- **일상 밀착성**: 약속 전, 이동 중, 공강처럼 누구에게나 반복적으로 생기는 공백시간을 활용합니다.
- **차별성**: 정해진 콘텐츠를 그대로 주는 게 아니라, 사용자가 가진 분 단위 시간에 맞춰 실제 콘텐츠 길이를 초 단위로 계산해 코스를 재구성합니다.
- **실현 가능성**: 별도의 하드웨어나 공간 구축 없이 LLM API, 유튜브 API, 사용자 상태 데이터만으로 구현했고, 실제로 모바일 웹 서비스 형태로 배포까지 마친 상태입니다.

## 📈 기대 효과

무의식적인 숏폼 소비를 줄이고 공백시간을 실제 휴식 시간으로 바꾸는 것, 하루 10분이라도 자신을 챙기는 행동을 반복하며 웰니스에 대한 진입장벽을 낮추는 것, "오늘도 시간을 버렸다"가 아니라 "오늘 15분은 나를 위해 썼다"는 경험을 주는 것이 틈틈이 만들고 싶은 변화입니다.
